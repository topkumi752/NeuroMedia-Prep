## 🚀 How to use the software

This tool organizes your video workflow into clear stages. You can split, convert, or process files using simple controls.

### Splitting and cutting videos
Use the split feature to divide long sessions into smaller, manageable files. This is useful for neurofeedback training sessions that require specific start and end times.
1. Load your video file into the main window.
2. Use the timeline slider to find your cut points.
3. Select "Auto-detect" if you want the tool to find natural scene breaks for you.
4. Click "Split" to save the new clips to your folder.

### Converting media formats
The tool uses FFmpeg to handle conversions. You can change your raw recordings into standard formats like MP4, MOV, or AVI.
1. Drag your video file into the "Converter" tab.
2. Choose your target format from the dropdown menu.
3. Select a destination folder for your new files.
4. Press the "Start" button to begin the conversion process.

### Working with subtitles
You can add, burn, or synchronize subtitles to your videos.
1. Import your subtitle file along with your video.
2. Use the synchronization tool to align the text with the audio track.
3. Select "Burn-in" if you want the subtitles to become a permanent part of the video frame.

## 🛠️ Frequently asked questions

**Does the tool delete my original files?**
No. The software always creates new, separate files for your processed media. Your original source files remain unchanged in their original location.

**How do I update to a newer version?**
Visit the release page again. Download the new installer and run it. The setup wizard automatically replaces the old version with the updated one while keeping your settings intact.

**Can I process multiple files at once?**
Yes. Use the "Batch" tab to add a folder of videos. The tool processes each file in the queue one by one.

**Does it require an internet connection?**
The tool runs offline. You only need an internet connection to download the initial installer and any future updates.

**What should I do if the software freezes?**
Check your disk space first. If you have plenty of space, close other video-heavy programs and restart the application.
